DeepSeek 设置

在 platform.deepseek.com/api_keys 创建，需先充值。
慢多半是模型或排队：Pro 先思考再输出，最慢；Flash 只输出结果，最快。图片题强制走 Flash。
高级 · 接口地址
默认 https://api.deepseek.com，一般无需修改。
只清空本机 API Key 与接口地址，错题本保留。

怎么用

  1. 填好 API Key 并保存，点「测试连接」确认可用。
  2. 上传错题照片，AI 自己识别题目文字并解析，只保存文字，不保存图片，省空间不卡顿。
  3. 结果自动进错题本；「考点查询」看高频考点与真题年份。
  4. 导出 Markdown 复习。数据都存在你这台设备的浏览器里。
为什么时快时慢：DeepSeek 服务器忙时排队，首字能等 30 秒以上，闲时几秒就回。Pro 还要先"想"再答，更慢。页面现在会显示已用秒数和收到字数，动着就是在跑。
识别不出来：多半是照片糊、反光或只截了半道题。裁剪时把题干和四个选项都框进去，字要清楚。AI 返回残缺时页面会自动重试最多 3 次。
注意：换设备或清浏览器数据会丢失记录，重要错题记得导出 Markdown 备份。

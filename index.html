怎么用

  1. 填好 API Key 并保存，点「测试连接」确认可用。
  2. 上传错题照片，AI 自己识别题目文字并解析，只保存文字，不保存图片，省空间不卡顿。
  3. 结果自动进错题本；「考点查询」看高频考点与真题年份。
  4. 导出 Markdown 复习。数据都存在你这台设备的浏览器里。
